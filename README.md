Este repositorio contiene el código fuente de un proyecto personal iniciado a principios del año 2026. Posteriormente, la aplicación fue utilizada como caso práctico de referencia para el desarrollo y la resolución de las consignas del Trabajo Final Integrador (TFI). En la actualidad, el sistema se encuentra desplegado en un entorno de producción y proporciona servicio operativo a dos clientes reales.
